# 議事録モード

議事録・打合せ記録を書くときの参照。原則はインソースのビジネス文書（議事録）の型を要約したものであり、原文の転載ではない。

出典（要約の根拠）: [上司が"唸る"議事録の書き方｜株式会社インソース](https://www.insource.co.jp/businessbunsho/gijiroku_by_insource.html)

## When to use

次のいずれかに当てはまるとき、本モードを使う。

- ユーザーが議事録、打合せ記録、MTGメモの清書・再構成を求めている
- 文字起こしやメモから、決定・宿題・未確定を読者向けに整える必要がある
- 情報・業務文書モードのうち、特に会議成果の共有が目的の文書

広告・販促や創作表現の技法は持ち込まない。Japanese Writing の Target quality と Quality gate をそのまま適用する。

## Pyramid structure

議事録はピラミッド構造で書く。上ほど要約、下ほど詳細。

1. **標題**: 会議の内容を一言で総括する（プロジェクト名＋議題＋議事録）。
2. **内容要旨（決定事項）**: 詳細を3〜5項目程度に圧縮する。決定と持ち帰りを区別する。要旨はおおよそ200字前後を心がける（会議規模で増減可）。
3. **詳細内容**: 見出し → 小見出し → 説明文の三段で書く。見出しは小見出しの要約、小見出しは説明文の要約。

詳細も時系列の生ログではなく、**テーマ（論点）ごとの塊**に再配置する。読者が最初に知りたい結論・担当・期限を先に置く。

## Required header fields

対外共有を含む標準形では、次を欠かさない。

| 項目 | 書き方 |
| --- | --- |
| 日時 | 西暦。24時間表記。開始〜終了（分かれば）。曜日があれば併記。 |
| 場所 | 会議室名、オンライン等。 |
| 出席者 | 先方→当方、または組織別。分かる範囲で役職・所属。序列は実務上自然な順。 |
| 内容要旨（決定事項） | 番号付き。決定と保留／持ち帰りを明示。 |
| 詳細内容 | （１）（２）…と①②…の階層。発言の根拠は短く添える。 |
| 次回会議日程 | 日時・場所・内容・出席（想定で可）。 |

任意:

| 項目 | 書き方 |
| --- | --- |
| 宿題・担当 | 誰が・何を・いつまでに。 |
| 未確定事項 | 未決の論点だけを列挙。 |
| 所見 | **社内限りで任意**。対外送付稿には書かない。感想やAIメタ情報は書かない。 |

## Editing rules

- 発言順のまま並べず、テーマでまとめる。
- 発言者は `(名前)` または文末の `（名前）` で示す。分かる範囲だけ。不明なら無理に推測しない。
- 省略された主語・対象は、文脈から確実なときだけ補う。
- 数字、日付、寸法、金額、担当、期限は具体的に残す。
- 「誰が・何を・いつまでに」が宿題になる箇所は曖昧なまま残さない。
- 内容要旨は読者優先。決定 → 方針合意 → 持ち帰り／次回、の順を基本にする。
- 雑談、既知の前提の繰り返し、同意の連打は削る。反対意見や条件付き合意は残す。

## Project overrides（本ユーザー案件）

次はインソース一般論より優先する。

1. **項目ごとのタイムスタンプ禁止**: `【HH:MM:SS】` や見出し横の時刻印は付けない。
2. **出力メタ禁止**: AI使用、ASR／文字起こしの注意書き、制限・免責、自動生成である旨の記載は本文に書かない。
3. **em dash禁止**: `—` や類似のダッシュで文をつないだり間を演出したりしない。
4. **1トピック1行**: 各決定・論点・宿題は1行の箇条書きにする。1行に1トピックだけを書く。
5. **重要事項先行**: 内容要旨（決定事項）を先に置き、運営・設計などの補足詳細は後に置く。
6. **言語版の順序**: 日本語版を最終確定してから英語版を作成する。英語版は日本語最終版の対訳とし、日本語にない情報を足さない。
7. **共有版の履歴と下書き**: 共有フォルダへ置く版はコピーして編集履歴を残さない。最終版以外の下書きは削除する。
8. **品質ゲート**: 本リポジトリの Japanese Writing（Target quality / Quality gate / plain-japanese-boundaries）を満たす。演出過多・翻訳調・ポエム調にしない。

## Preferred shared format（本ユーザー案件）

共有用の標準形は次を優先する（詳細の長文階層よりこちら）。

1. 標題
2. 日時／場所／出席
3. 内容要旨／決定事項（1トピック1行）
4. 補足（運営）（1トピック1行）
5. 補足（設計・工程）（1トピック1行）
6. 宿題（1トピック1行）
7. 次回会議
8. 主な未確定（あれば）

英語版を作るときは、上記と同じ見出し順・同じ粒度で対訳する。

## Minimal skeleton

```
# ○○プロジェクト｜○○打ち合わせ 議事録

## 日時
YYYY年M月D日（曜）HH:MM〜HH:MM

## 場所
…

## 出席者
- 先方／組織A：…
- 当方／組織B：…

## 内容要旨（決定事項）
1. …
2. …
3. …

## 詳細内容
### （１）…の件
#### ①…
- 文。（発言者）

## 次回会議日程
日時：…
場所：…
内容：…
出席：…

## 宿題・担当
…

## 未確定事項
…
```

社内のみで所見が必要な場合は、未確定事項の後に `## 所見` を置き、対外稿では削除する。
